# 100_GitHub · 公開学習ノート

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

数学・物理の個人学習内容を整理し、共有するリポジトリです。概念の説明、式の導出、必要な補足知識を扱います。各ノートを独立して読めるようにし、出典を追跡できる形で、読者からの指摘を通じて継続的に改訂することを目指しています。

原則として、中国語・英語・日本語の独立した稿件を作成し、読みやすい PDF と編集可能な LaTeX ソースを提供します。3言語版は主要な内容、記号、節構成、式番号を共有しますが、ページ数や改行位置は異なる場合があります。

内容は個人の学習整理であり、授業や大学の公式解答ではありません。各稿件に記載された仮定、適用範囲、改訂版を確認してください。

## PDF の作成方法

学習稿件は「著者による手書きの導出 → AI による電子原稿の整理支援 → LaTeX による PDF の生成」という手順で作成します。著者が手書きの考え方、計算、導出を提供し、AI が文字・数式の認識と転記、構成整理、翻訳、LaTeX の組版を支援します。元の導出と、その後の編集作業を区別します。

認識、翻訳、記号、組版には誤りが残る場合があります。確認状況は各稿件の説明に従い、この説明をもって全稿件が著者により逐一確認済みであるとはしません。添付する手稿写真との照合や指摘を歓迎します。別の形式の素材を使用した稿件では、その旨を個別に説明します。

整理に用いる [200_github_open_learning_pdf skill](skills/200_github_open_learning_pdf/SKILL.md) と [LaTeX テンプレート](skills/200_github_open_learning_pdf/assets/open_learning_template.tex) を収録し、整理規則を確認・再利用できるようにしています。手稿写真は公開権限と個人情報を確認し、必要に応じてプライバシー処理を施した公開用コピーを収録します。3言語版は同一の手稿画像を共有します。

このライセンスは複製、再配布、翻訳、改変、商用利用を認めます。再利用時には、ライセンスに従って適切な著者・出典情報を保持し、ライセンスへのリンクを提供し、変更の有無を明示してください。原著者が利用を支持していると示唆してはいけません。

公開著者名は現在未指定であり、決定後はハンドルネームを使用します。現段階では作品名、版、元資料へのリンク、既存の帰属情報を保持してください。後日著者のハンドルネームが提供された場合は、その表示も保持してください。

**第三者の資料は、収録や引用によって自動的に本リポジトリのライセンスになるわけではありません。** 参考書、授業の問題、講義資料、転載図表、フォントなどの第三者の内容には、それぞれのライセンス、許諾、適用される引用規則が適用されます。該当する例外と出典は、対応するファイルや箇所に明記します。文献へのリンク自体はリンク先の利用許諾を与えません。

## フィードバックと改訂

式の誤り、仮定の不足、記号の不一致、分かりにくい説明、翻訳の問題についての指摘を歓迎します。

- **Issues**：具体的な誤りや改善案を報告してください。ファイル名または題名、言語版、改訂版、節、式番号または短い引用、問題の説明を記載してください。修正案や参考資料があれば併記してください。
- **Discussions**：理解上の疑問、別の導出方法、学習上の提案を議論します。この機能が有効になった後に利用できます。有効になるまでは Issues で質問しても構いません。
- **Pull requests**：ソース、翻訳、組版の変更を提案してください。変更理由を説明し、可能な範囲で3言語版の対応内容を確認してください。LaTeX の変更ではコンパイルを検証したかも記載してください。

GitHub への公開後は、リポジトリのページからこれらの窓口を利用できます。確認できた問題は以後の改訂で対応します。報告には学籍番号、個人の連絡先、公開の許諾がない授業資料、その他の個人情報を含めないでください。
