# ランダウ学習ノート：テンソルと相対論的運動学

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

バージョン0.7、2026-10-20。混合テンソル、ミンコフスキー計量と逆計量、δ／εと双対、極ベクトルと軸ベクトル、四次元の微分と積分、四元速度と四元加速度を扱います。線形代数、微積分、特殊相対論の基礎を前提とします。

著者の手書きの導出と2件のWord説明文をもとに、AIが転記、構成整理、翻訳、LaTeX組版を支援しました。著者による複数回の修訂と中国語ソースの手動編集を反映しています。各版はコンパイルと全ページの組版確認を済ませていますが、全ての数学的主張の独立した検証を意味しません。
