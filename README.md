# 100_GitHub · 开放学习笔记

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

整理并分享个人数学、物理学习内容，包括概念说明、公式推导和必要的补充知识。目标是让笔记能够独立阅读、追溯来源，并在读者反馈中持续修订。

稿件默认分别提供中文、英文、日文版本，以及便于阅读的 PDF 和可编辑的 LaTeX 源文件。三种语言版本保持相同的主要内容、符号、章节与公式编号；页数和换行可能不同。

这些内容属于个人学习整理，不代表课程或学校的官方答案。阅读时请留意各篇注明的前提条件、适用范围和修订版本。

## 反馈与修订

欢迎指出公式错误、遗漏的假设、符号不一致、难以理解的步骤和翻译问题。

- **Issues**：报告具体错误或提出明确的改进建议。请写明文件或题名、语言版本、修订版本、章节、公式编号或短摘录，并解释问题；如有建议修改或参考来源，也请附上。
- **Discussions**：讨论理解上的疑问、不同推导方式或学习建议。该功能开启后可使用；尚未开启时可先通过 Issues 提问。
- **Pull requests**：提交源稿、翻译或排版的修改建议。请简述修改原因，并尽可能核对三种语言版本的对应内容。若修改 LaTeX，请注明是否已编译验证。

仓库发布到 GitHub 后，可在仓库页面使用这些反馈入口。问题经核查后会通过后续修订处理；提出问题时请勿上传学号、私人联系方式、未获准公开的课程材料或其他个人信息。
